2Do you need ID verification for the person onboarding?Better MVP solution - we will use a light authorisation + trust model instead.

MVP trust controls:
Work email preferred
Company name + Companies House match
Company registration number
Role declaration
Email verification
Open banking / accounting / business evidence later in flow
Admin review flag where suspicious

Note - For MVP, we will use an authorised representative model with lightweight business verification and declarations, rather than full ID verification.
6
3Can bank account validation act as a trust / KYC proxy?For MVP: Banking / accounting connectivity should be treated as: a trust-enhancing data source, not our only access control mechanism.
7
4What data should come from APIs vs questionnaires vs uploaded evidence?For MVP, our data strategy should be: Hybrid, lightweight, and controlled

That means:
A. API / Auto-populated data (MVP) - Companies House (company details / registration basics); Open banking / accounting (only if included); limited benchmark or reference data.
B. Questionnaire-based data (MVP) - This should be a major part of the MVP, because for SMEs, many ESG / operational / readiness indicators will not exist cleanly in public APIs. So yes, we absolutely need: structured onboarding questions and sustainability / operational / financial readiness questions.
C. Document / evidence upload (MVP) - Yes, but only lightly and selectively. Only allow upload where evidence is genuinely necessary. Examples: optional supporting document, basic proof for specific ESG or business claims, and maybe selected company docs if relevant.
8
5Should uploaded evidence be manually validated by humans?Yes, for MVP, use selective human validation where needed. MVP should include: manual review / admin validation for selected high-trust evidence cases.
We will use a tiered trust model:
Tier 1: Self-declared / low-risk inputs - no manual review needed. Examples: questionnaire responses and general company profile info.
Tier 2: System-supported inputs - Auto-supported / structured Examples: Companies House data, financial data imports, and benchmark calculations.
Tier 3: Evidence-backed claims - Manual review if used in material outputs. Examples: certificates, claimed ESG achievements, and specific verified assertions.
