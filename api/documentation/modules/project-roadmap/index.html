Note for project management

Hi — I've put together a summary of my role, what I've done on the project so far, and how I'm planning to take things forward for the JusKel Sustainability Finance Hub (MVP). I'm sharing this ahead of our group meeting so we can stay aligned on delivery and timelines.

My role on this project

Engineering lead — backend & platform documentation

I am responsible for establishing the technical foundation of the JusKel platform and delivering the backend API alongside supporting documentation that keeps engineering, product, and stakeholders aligned.

  • Define and document architecture, tech stack, and module boundaries
  • Scaffold and build the .NET 10 API and SQL Server data layer
  • Coordinate with the Next.js client team on API contracts and flows
  • Maintain the technology documentation site as a living source of truth
  • Translate discovery requirements into implementable, phased delivery plans

Project objective

My goal is to deliver the JusKel Sustainability Finance Hub MVP — a secure, scalable web platform on the Microsoft ecosystem that proves the SME-side value loop: sustainability scoring, funding readiness, and funding match — with optional lean lender participation.

Commercial wedge: SME first · Lender progressive · Corporate pilot · Climate fintech core as infrastructure expansion.
