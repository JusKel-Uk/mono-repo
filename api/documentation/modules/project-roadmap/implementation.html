Q1 – Q2 2026 · Complete

Discovery & requirements

I worked through product discovery, the MVP requirement catalogue, business rules, user stories, master product roadmap, and initial tech stack evaluation.

  • MVP Requirement Catalogue finalised
  • Build phasing defined (Lean MVP → Year 1 → Year 1.5/2)
  • Microsoft ecosystem alignment agreed
July 2026 · Complete

Repository & architecture foundation

I established the monorepo, engineering workflow, and documented our technology decisions.

  • GitHub monorepo (dev branch, feature branches, PR workflow)
  • Tech stack confirmed: .NET 10, SQL Server, Next.js, Azure
  • Technology documentation site launched (modular, hostable)
  • Platform and sign-in modules documented
Aug – Sep 2026 · Current

API scaffolding & platform core

I'm now moving into hands-on engineering — project setup, authentication, and the database foundation.

  • .NET 10 API project scaffold (modular monolith structure)
  • SQL Server schema — users, roles, audit logs
  • Sign-in / auth module implementation
  • CI pipeline and Azure environment setup
  • API contract alignment with Next.js client
Oct – Nov 2026

Lean MVP core features

I plan to build the SME value loop — scoring, funding match, and the readiness dashboard.

  • Rule-based sustainability scoring engine
  • Funding match logic and product eligibility rules
  • Companies House API integration
  • SME onboarding and profile capture
  • Azure OpenAI — score explanations and summaries (assist only)
  • Document upload via Azure Blob Storage
Dec 2026 – Q1 2027

Integration, QA & pilot readiness

End-to-end testing, security review, and pilot preparation.

  • Frontend–backend integration testing
  • Security hardening and penetration review
  • Admin tooling for pilot operations
  • Optional lean lender module (design partner)
  • Pilot onboarding and support documentation
Q1 – Q4 2027 · Layer 2

Year 1 commercial rollout

Commercialise SME product; expand lender and corporate pilot modules.

  • ESG Lite Toolkit and improvement roadmap
  • Enhanced lender workflows (review notes, handoff pilots)
  • Corporate pilot modules (scorecard, benchmarking)
  • Controlled Xero / QuickBooks integration
  • Power BI reporting exploration
2027 – 2028 · Layer 3

Advanced platform expansion

Deeper integrations, workflow maturity, and ecosystem connectivity.

  • Open Banking (TrueLayer / Yapily)
  • Microsoft Entra ID / SSO
  • Azure Service Bus event-driven workflows
  • Climate data APIs and advanced ESG providers
  • Model governance and mature consent framework
