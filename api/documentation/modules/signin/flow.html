Sign-in — Flow

Request and response flows for authentication operations.

Overview Schematics Flow Implementation

Sign-in flow

1. Client submits credentials → 2. Validate input → 3. Verify password → 4. Issue JWT → 5. Return tokens

Flow steps

1. Credential submission

Client sends POST request with email and password to the sign-in endpoint.

2. Input validation

Controller validates request format. Returns 400 if email or password is missing or malformed.

3. Credential verification

Auth service looks up user by email, compares password hash. Returns 401 on invalid credentials.

4. Token issuance

On success, generate access token (short-lived) and refresh token (long-lived).

5. Response

Return 200 with tokens, user profile summary, and assigned roles.

Sequence diagrams and error flows will be added during implementation.
