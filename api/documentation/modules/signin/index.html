Sign-in

Authentication, session management, and identity verification for platform users including SMEs, lenders, and admins.

Planned
Overview Schematics Flow Implementation

Overview

Purpose

The Sign-in module handles user authentication across all JusKel platform personas. It will support secure credential validation, session token issuance, and role-based access control integration.

Scope

  • Email and password authentication
  • JWT or session-based token management
  • Role assignment (SME, Lender, Admin)
  • Password reset flow (future phase)
  • Microsoft Entra ID integration (future phase)

Available documentation

  • Schematics — architecture and component layout
  • Flow — authentication request/response flows
  • Implementation — endpoints and build status
