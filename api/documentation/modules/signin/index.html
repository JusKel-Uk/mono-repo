Sign-in & Identity

Registration, OTP email verification, JWT sessions, and protected routes for the juskel platform.

MVP Live
Overview Schematics Flow Implementation

Overview

Purpose

The Identity module (identity.Core) handles user onboarding and authentication. New users register with a business email, receive a 6-digit OTP by email, and must verify before signing in. The API returns HTTP 403 with errorCode: EMAIL_NOT_VERIFIED when credentials are valid but verification is pending — so the frontend can route to OTP entry or resend.

Implemented (MVP)

  • User registration with business-email validation
  • OTP generation, hashing, and branded email (Resend / Console)
  • Email verification endpoint
  • OTP resend endpoint (anti-enumeration safe)
  • JWT sign-in gated on emailVerified
  • GET /identity/me (Bearer token)

Planned

  • Refresh tokens and sign-out
  • Password reset flow
  • Role claims (SME, Lender, Admin)
  • Microsoft Entra ID integration
