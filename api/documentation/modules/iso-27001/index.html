ISO 27001 — Azure Technical Roadmap

Technical Lead execution plan for ISO/IEC 27001:2022 certification, re-engineered for juskel's lean Azure MVP — Container Apps, custom JWT identity, bash deploy scripts, and $5–15/mo budget constraints.

Purpose

This module translates enterprise Azure ISO 27001 guidance into actions that fit juskel's actual codebase: deploy-azure.sh, the identity module, Log Analytics at bootstrap, and no CI/CD yet. Auditors weight proportionality — documented risks with a credible remediation plan beat expensive controls nobody maintains.

Six pillars (juskel-adjusted)

1. Isolation & IaC

Resource groups first, Bicep later. No multi-subscription overhead yet.

2. Zero-trust identity

MFA on Azure admins; document custom JWT for app users; SQL Managed Identity.

3. DevOps & pipelines

GitHub Actions + OIDC. Biggest gap — fix before audit.

4. Encryption & backup

TDE (default), Key Vault for secrets, quarterly SQL restore drill.

5. Logging & monitoring

Build on existing Log Analytics. App Insights, not Sentinel yet.

6. Audit prep

Defender for Cloud ISO dashboard, Stage 2 screen-share script.

Top five priorities

  1. GitHub Actions CI/CD — audit trail for every deploy
  2. Key Vault — stop laptop-deploying prod secrets
  3. SQL Managed Identity — remove DB password from connection strings
  4. Application Insights + SQL audit logs → Log Analytics
  5. ISMS + Statement of Applicability — map actual architecture to Annex A
