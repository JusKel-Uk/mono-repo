Authentication

All endpoints require Authorization: Bearer <accessToken> from POST /identity/sessions.

Onboarding module (onboarding tag)

MethodPathDescription
POST/onboarding/applicationsCreate draft application (idempotent)
GET/onboarding/applications/currentProgress: completedCount, totalSteps (5), canSubmit, per-step status
GET/PUT/onboarding/applications/current/company-setupStep 1 — company identity + CH verify
POST/onboarding/applications/current/company-setup/verify-companies-houseCH lookup (rate-limited 5/min)
GET/PUT/onboarding/applications/current/business-profileStep 2 — sector, region, bands, description
POST/onboarding/applications/current/submitSubmit when all 5 steps complete

Application-scoped variants also exist: /onboarding/applications/{applicationId}/...

Step order

  1. Company setup
  2. Business profile
  3. Financial profile
  4. Sustainability profile
  5. Funding profile

  • Integrations:Xero, Integrations:QuickBooks

Database schemas
