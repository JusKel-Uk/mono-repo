Purpose

This module documents the SME onboarding wizard API derived from Figma flows in discovery/figma_images/onboarding-flows/. Use this spec during BUILD SESSIONs — you should not need to open the images again.

How to build (learning workflow)

  1. Open api/BUILD_SESSION_ONBOARDING.md
  2. Start at M1 (M0 docs are already here)
  3. One milestone per session; agent instructs, you type code
  4. Say "I'm done" for verify + score
