# JusKel Monorepo

Monorepo for the JusKel platform — a fintech lending solution.

## Structure

| Directory   | Description                          |
| ----------- | ------------------------------------ |
| `api/`      | Backend API                          |
| `client/`   | Web client                           |
| `discovery/`| Product discovery and requirements   |

## Tech Stack

### API (`api/`)

- **.NET 10**
- **SQL Server**

### Client (`client/`)

- **Next.js**

## Getting Started

> Setup instructions will be added as each project is scaffolded.

### Prerequisites

- [.NET 10 SDK](https://dotnet.microsoft.com/download)
- [SQL Server](https://www.microsoft.com/en-us/sql-server)
- [Node.js](https://nodejs.org/) (LTS recommended)
